# Costa Rica provincial boundaries

Unmodified geoBoundaries gbOpen CRI ADM1 simplified GeoJSON, boundary ID
CRI-ADM1-80129987. Seven provinces, represented year 2017. Illustrative map,
not a legal boundary reference. Downloaded 2026-10-19.

Source: OpenStreetMap, Wambacher, distributed by geoBoundaries.

https://opendatacommons.org/licenses/odbl/1-0/
https://www.openstreetmap.org/copyright
https://www.geoboundaries.org/api/current/gbOpen/CRI/ADM1/

Pinned original dataset:
https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/9469f09/releaseData/gbOpen/CRI/ADM1/geoBoundaries-CRI-ADM1_simplified.geojson

The original geometries are preserved, including offshore islands. The initial
viewport shows mainland Costa Rica; no office locations are inferred from this
dataset. Only the Cartago coordinates supplied by the user are marked.
